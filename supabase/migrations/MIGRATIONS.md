# Migration Log

Per-migration notes for `supabase/migrations/`. Split out of `CLAUDE.md` on 2026-07-31, where it had grown to 44 KB of an 83 KB always-loaded instruction file. Almost every row here is *history* (what a migration added, when it was applied, why it was shaped that way) rather than a rule to follow, so it belongs in a file you open on demand.

**`CLAUDE.md` keeps the rules that always apply** — the missing `028`, the PostgREST grant requirement for new `public` tables, and the revoke-before-grant ordering trap. This file keeps the record.

Read it when you need the history of a specific table, column, policy or view. Don't load it for general work.
